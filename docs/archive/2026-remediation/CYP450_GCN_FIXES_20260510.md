# CYP450 / GCN readiness fixes applied

This package update keeps the existing extraction logic unchanged and adds safer materialization/export behavior around the extracted graph.

## Applied fixes

1. **Empty ML CSVs now keep headers**
   - `negative_compound_target_pairs.csv` is intentionally empty unless the user provides confirmed negatives, but it now contains stable columns.
   - `candidate_missing_compound_target_pairs.csv`, training pairs, and link-prediction pairs also use stable schemas so pandas/Neo4j/GCN scripts do not fail on one-target runs.

2. **Reactome is bridged to the generic Pathway layer**
   - Existing `Reactome` nodes are now connected to generated `Pathway` nodes using `ALIGNS_TO_PATHWAY`.
   - Proteins mapped to Reactome are also linked to those generic pathways using `PARTICIPATES_IN`.
   - This works both during new builds and during `load-run --rematerialize-schema true` on an existing run folder.

3. **BioAssay and Reference metadata are normalized for readability**
   - BioAssay nodes now get `pubchem_url`, `display_title`, normalized assay fields where possible, and an explicit `assay_title_is_fallback` flag when PubChem RDF did not return a real title.
   - Reference nodes now parse/normalize PMID, DOI, year, reference type, PubMed/DOI URLs, and metadata-quality flags where available.

4. **Neo4j loading now applies the same metadata normalization**
   - Loading an existing run folder into Neo4j applies target, endpoint, and metadata normalization before upserting nodes.

5. **PDB and AlphaFold records include usable external URLs**
   - PDB rows include RCSB URLs.
   - AlphaFold rows include PDB/CIF/PAE URLs when available through the API.
   - If the AlphaFold API times out, PRING adds a clearly flagged `model_status=url_pattern_unverified` fallback URL pattern instead of silently losing the AlphaFold layer.

6. **Text-mining import is easier to use**
   - `--textmining-file auto` now checks common filenames under the working directory and input folders.
   - If no file is found, PRING writes `templates/textmining_cooccurrence_template.csv` and `templates/TEXTMINING_IMPORT_README.md`.
   - Text-mined co-occurrence evidence remains separate from curated PubChem assay evidence.

## Recommended command for rematerializing an existing run

```powershell
python -m pring load-run `
  --run-dir runs\YOUR_RUN_FOLDER `
  --rematerialize-schema true `
  --rematerialize-csv true `
  --load-neo4j false
```

Then check:

```text
graph/nodes_csv/Pathway.csv
graph/rels_csv/ALIGNS_TO_PATHWAY.csv
graph/rels_csv/PARTICIPATES_IN.csv
graph/ml/negative_compound_target_pairs.csv
graph/ml/candidate_missing_compound_target_pairs.csv
```

## Important modeling note

`negative_compound_target_pairs.csv` is intentionally header-only unless confirmed negatives are provided by an external source. For CYP450 GCN link prediction, unobserved compound-target pairs should be treated as **unknown candidates**, not true negatives.
